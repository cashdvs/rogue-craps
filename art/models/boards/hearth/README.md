# Hearth board (locked direction, Oct 18, 2026)

Original work by Tiny Anvil Games, generated by `src/build_hearth.py` (Blender 4.5 LTS), `src/make_hearth.gd`,
`src/make_flame_atlas.py` and `src/make_felt_motif.py` (no third-party meshes or textures). Proprietary, same
terms as the rest of the repo (see `LICENSE`).

Spec: `art/concept/bonfire_table/README.md` "LOCKED DIRECTION" (refs `board_1_hearth.jpg`,
`board_3_candle_shrine.jpg`), `art/concept/burnline_boards/board_kit.md` sections 1-8,
`art/concept/fire/fire_style.md`.

The Hearth **is Board A (infernal_pit)**: same felt, rails (collider-matched), studs, backboard,
body, total dial, near corner caps, the same node tree and the same anchors. It only changes slot
contents, overrides two materials and adds one `Hearth` subtree. Art only: no gameplay code, no
colliders, no light nodes (everything glows with emissive; the table's Lamp3D lights it).

## Hooks for Godot Dev (all on the `Hearth` node; visual only)

```gdscript
var fx = board.get_node("Hearth")
fx.pot_step = 0..4     # brazier fire: 0 coals, 1 tongue, 2 crown of 3, 3 five + ember sparks, 4 twisting column + brass spiral sparks + smoke curl cap
fx.eyes = 0..3         # both demon faces: off / ember / hot / white-core (Hot Hand 0/1/2/3+)
fx.eyes_left = -1..3   # optional per-face override (-1 = follow eyes); eyes_right likewise
fx.fill = 0.0..1.0     # ember cauldron (bank)
fx.lit_count = 0..8    # progress candles (12.5 % of the table goal each); reaching 8 plays "flare"
fx.seam = 0.0..1.0     # idle glow of the ember seam (default 0.6)
fx.pulse_seam()        # one 0.15 s seam pulse (per lit die); SeamPlayer "seam_pulse", overlaps other clips
fx.bust()              # AnimationPlayer "snuff": everything out, charcoal smoke wisps, relights to the previous state
```

AnimationPlayer clips (`Hearth/AnimationPlayer`, root = `Hearth`), all drawn on twos (discrete keys, 12 fps):

| Clip | Length | Keys |
|---|---|---|
| `snuff` | 0.75 s | `snuff` 0.4 / 0.7 / 1.0 (out by 0.17 s), hold, 0.6 / 0.3 / 0 (relit at 0.67 s); `wisp` 0.08-0.5 s. Out ~0.5 s |
| `flare` | 0.6 s | `flare` 1.0 -> 0 in 6 drawings (candle tongues grow x1.9, cores boost) |
| `RESET` | - | snuff / wisp / flare = 0 |
| `SeamPlayer/seam_pulse` | 0.15 s | `pulse` 1.0 / 0.5 / 0 |

The clips key only `snuff`, `wisp`, `flare` and `pulse`, never the state params, so a bust cannot
lose progress (the test checks this). The lower-level per-prop params are also exported if needed:
brazier `step / heat / wisp`, demon face `eyes / heat`, cauldron `fill / heat / wisp`, candle
`lit / heat / flare / wisp / height`. `heat` = 1 - snuff.

## Fire (fire_style.md)

The toon tongue flipbook from the paused fire WIP (`art/toon-fire-vfx` fd42d78), **copied** here
so the board does not depend on the dice fire (fire stays off the dice): `textures/flame_tongue_4x4*.png`,
`smoke_curl.png`, `src/make_flame_atlas.py`, `shaders/hearth_flame_card.gdshader` (= toon_flame_card +
flare grow + wisp rise). SDF bands: Butter #FFE6A8 core (the only band > 1.0, so the only bloom),
Ember #E8622A, Hellfire #C8281E, Oxblood #3B0D14 outer outline; 12 fps on twos, random start frame +
mirror per card, Y-locked billboards, alpha-cut. Sparks are 4-point diamonds (`hearth_sparks.gdshader`,
self-animated in one mesh, no particle nodes). Candle flame = the tier-1 tongue at 0.75 scale
(0.03 m visible). Step 4 = 8 tongues capped at ~0.30 m above the coals with a wider flare (+-0.1 m),
plus a slow drifting diamond spark field (`sparks_drift.tres`) above the column that fades out. Smoke wisp = `smoke_curl.png`, charcoal #1E1B1A with a Pit Black outline.

## Other shaders (`shaders/`, all share `hearth_instance.gdshaderinc`: instance `heat`, `level`, `pulse`)

- `ember_seam.gdshader`: the seam is drawn on the existing rail mesh (no new geometry): a next pass
  pushed 0.7 mm out that keeps only a UV.y band (0.125 +- 0.012 = the inner top lip ~8 cm above the felt, clear of the backboard strip,
  all the way round). Pit Black groove edges, Ember fill (`level`), Butter core on `pulse`.
- `demon_eye.gdshader`: hard radial bands around the two eye centres; 0 a faint ember smoulder (`idle_energy` 0.9),
  1 ember + slit pupil, 2 butter core (blooms), 3 white core. Eye area 2x the first pass (0.0163 x 0.0096 m), energies
  2.4 / 3.2 / 4.5. Readability over carving detail.
- `hearth_glow.gdshader`: unshaded additive ellipse lying on the rail top under each LIT candle (Ember outer, Butter
  inner, flicker on twos). A fake glow decal, no light.
- `hearth_coals.gdshader`: charcoal with stepped ember cracks / butter hot spots, flicker on twos; brighter with the pot step.

## Art Director revisions (Oct 18, pass 2)

- Candles: flame 0.75 scale; lit wax swaps to `candle_wax_lit.tres` (Butter emissive rim + warm emission); unlit wax
  keeps a dim emission floor so its silhouette stays visible; additive `Glow` decal under each lit candle (no light).
  Candle yaw / glow tilt are script exports (`spin`, `glow_tilt`), so the instance roots stay unrotated.
- Brazier: step-4 column capped at ~0.3 m with a wider flare; drifting diamond sparks above it. Solid fire never
  covers the dealer's face at any step from the game camera (checked by the test against Smiles' face at
  x = -0.42, y 0.2, z -0.86; sparks may cross his chest). See the dealer note below.
- Seam: shows on the far and side rails only. Accepted that the near rail does not show it (AD: no change).
- Demon faces (FL / FR caps) and the ChipTray cauldron: approved. Eyes bigger and brighter, faint glow at eyes = 0.
- Felt: `hearth_felt_motif.png` lifts the felt toward the edges / corners (Underfelt-teal edge ramp under the motif)
  and the felt has a low Underfelt emission floor, so dice never fall into near-black in the vignette.
- `Hearth/Candles` subtree: approved as is. The Art Director will document it in board_kit.md.

Props are drawn at the dice's scale (the 0.08 m dice on a 2 m felt), use the prop ink `ink_prop.tres`
(0.0025 = 60 % of the dice outline) and carry a faint self-glow of their own albedo: the dressing sits
outside the lamp cone, where the toon ramp is black, and reads by "candlelight". v2: the prop materials are
`hearth_toon_detail` with a thin unlit warm rim (`rim_emit`, Ember or brass, grazing edges only) to cut them
off the black backdrop; the tail's rim is Ember on its top edge only (`rim_emit_up`), 22 deg of hue and well
under the brightness of Danger red. Ceiling: glow + rim <= 60 % of the dice value, nothing more saturated
than Ember (checked per material by the test). No fire on dice, no occult symbols, no Soul cyan / Danger red.

### Hooks (on the `Hearth` hub; forwarded to `Hearth/Dressing`)

```gdscript
fx.dressing = true|false  # everything on / exactly the pre-pass board (felt, leather, Board A studs)
fx.ambient = true|false   # ambient motion (motes, dust, tail peeks, chain, bell); off for reduced motion
fx.scoring = true|false   # while a score shows: the tail whips back if out and does not peek again until false
fx.rail_hit(strength)     # a die hit a rail: ChainPlayer "chain_sway" (0.4 s), amplitude x strength (0.2-1.5)
fx.bell_ring()            # Smiles' bell rattles (BellPlayer "bell_rattle", 0.5 s); fx.eyes reaching 3 calls it
# Dressing.set_next_peek(seconds) schedules the next tail peek (renders / tests); peek_min / peek_max = 8 / 15 s
```

Gameplay never has to call anything: with no hooks the tail still peeks every 8-15 s. Godot Dev may wire
`rail_hit` to the die-rail contact signal and `scoring` to the score display; no gameplay code was changed.

| Player / clip | Length | Keys (on twos) |
|---|---|---|
| `TailPlayer/tail_peek` | 1.8 s | `tail_out` 0 -> 1 in 3 drawings, a 2-bone sway + a twitch, back in 2 drawings |
| `TailPlayer/tail_whip` | 0.17 s | straight back under (scoring) |
| `ChainPlayer/chain_sway` | 0.4 s | `chain_swing` 1, -0.65, 0.4, -0.22, 0.1, 0 |
| `BellPlayer/bell_rattle` | 0.5 s | `bell_shake` +-1 decaying |

The clips key only the pose params (`tail_out / tail_sway / tail_curl / chain_swing / bell_shake`).

## Notes / spec gaps

- Board A has no `RailLeft` / `RailRight` anchors; the candles live under `Hearth/Candles/RailLeft|RailRight` (new nodes, the Board A tree is untouched).
- The goal plaque node keeps Board A's name `Plate` (board_kit.md §8 calls the slot `goal_plaque_scene`).
- The demon faces take the `Cap` nodes of Corner_FL / FR (replacing the brass caps there).
- The cauldron switches on the §8-optional `ChipTray` slot.
- Fire steps 3-4 rise above 0.25 m (step 4 column top ~0.5 m world). Effects cards, not geometry; all geometry stays under 0.25 m.
- Dealer placement: from the game camera (pitch 55, distance 2.5, FOV 36) only ~0.03-0.29 m of height is visible
  above the brazier rim at the dealer's depth (z -0.86), and a centred dealer is hidden by the bowl itself. So
  Smiles stands **stage left at x ~ -0.42** (head beside the brazier), and only his head / shoulders read in the
  game camera (spec gap: "waist up" is not visible there; it is in 3/4 and close-ups).
- The controller scripts (`scripts/*.gd`, `@tool`) are visual-only setters (instance uniforms + visibility); they are additions on top of the art-only Board A rule.
- Follow-up (QA on #111): `src/make_hearth.gd` (763 lines) and `src/build_dressing.py` (583) are over the ~400-line
  guideline; split them (e.g. make_hearth: materials / props / board / dressing; build_dressing: corners / under /
  chain + bell + tail) in a later art-only PR, rebuilding to byte-identical .glb / .tres.
- Phone portrait framing (CameraRig) crops the far rail as on Board A, so the brazier / goal plaque is off screen in portrait.
