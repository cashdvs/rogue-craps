# Dice models: Bone d6

Original work by Tiny Anvil Games, generated by `src/build_dice.py` (no third-party assets,
textures or fonts). Proprietary, same terms as the rest of the repo (see `LICENSE`).

| File | What |
|---|---|
| `bone_d6.glb` | Bone d6: pips 1-6, opposite faces sum to 7. One mesh (`BoneD6`), two material slots (`bone_body`, `bone_pip`), 1,988 tris. No collision, pivots, cameras or animations |
| `bone_d6.glb.import` | Maps the two slots onto the toon materials below, turns LODs and animation import off |
| `materials/bone_body.tres`, `bone_pip.tres` | Toon materials (`shaders/3d/toon_noir.gdshader`) with the same values as `DieVisual` / `Toon.inked`. The body has the ink hull (`die_ink_outline.tres`: `outline.gdshader`, 0.0042 m, mode 1 = push from centre, so the hull has no gaps at hard edges) as its next pass |
| `src/build_dice.py` | The source. Rebuild: `blender -b --factory-startup --python art/models/dice/src/build_dice.py` (Blender 4.5 LTS) |

## Scale and face convention (matches `scripts/table3d/die_visual.gd`)
- Godot axes: metres, +Y up, -Z forward, scale 1, centred at the origin. 0.08 m cube
  (`TuningData.die_size`), bevel 0.16 x edge.
- Face slot -> local normal (`DieVisual.FACE_AXES`): **1 = +Y, 6 = -Y, 2 = +X, 5 = -X, 3 = +Z, 4 = -Z**.
- Pip positions and the 2/3/6 diagonals use the same u/v axes as `DieVisual._add_pips`, so `value_up()`
  and `remap_basis()` work unchanged. `tests/test_dice_models.gd` checks this.
- Pips are drilled spherical caps, 18% of the face wide and 0.06 x edge deep (poc_3d.md 3, dice_rarities.md Bone).
- Physics is not in the asset: the dice physics code builds its own `BoxShape3D` (`die_size`).

## UVs
One 3x2 atlas (author at 3:2, e.g. 768x512). Slot s sits in column (s-1)%3, row (s-1)//3 from the top
(1 2 3 / 4 5 6). U follows the face's pip u axis. Each tile has 2% padding. No textures are used yet;
the layout is ready for edge wear, grime or a pip atlas.

## Special dice
Ten special dice live next to this one (batch 1: Mirror, Cracked, Hellfire, Gilded; batch 2: Twin Flame, Wanderer,
Bellows, Blood Pact, Coven, Last Breath). See `SPECIAL_DICE.md`. Source: `src/build_special_dice.py` and `src/write_batch2.py`.

## Special dice (history)
Special dice will get their own silhouettes and materials rather than reusing this cube; an astragalus
(knucklebone) shape is a candidate. The generator still has a parked Knucklebone spec (`--all`), but it is
not exported or shipped while the core loop is reworked.
