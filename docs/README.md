# docs/

| File | What it is |
|---|---|
| [DESIGN.md](DESIGN.md) | Public design summary: pillars, core loop, craps rules, Coin and Soul, the table goal, POC scope |
| [MODULES.md](MODULES.md) | Module ownership map: the game's sub-sections, who owns them, how to claim one |

The full, living design and art documents are maintained by the Tiny Anvil team and aren't in
this repo. Issues quote any extra numbers or specs they need. If something in `DESIGN.md` looks
wrong or out of date, open an issue rather than changing it in a feature PR; design changes need
the Game Designer's OK.
